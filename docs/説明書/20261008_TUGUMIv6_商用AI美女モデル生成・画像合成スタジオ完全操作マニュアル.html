第1章：システム概要と「超リアル実写 8大方程式」

本システムは、Google の最新モデル gemini-3.1-flash-image のネイティブ画像推論能力を最大限に引き出し、独自開発の ai-model-producer-pro SKILL を直結させた実写特化型スタジオです。素人生成にありがちな「陶器肌」「プラスチックマネキン感」を徹底排除し、実在する人物と区別がつかないレベルの写真を出力します。

🧬 ① Character DNA (同一人物性維持)

骨格、アーモンド型の瞳、涙袋、左目の下のホクロ、毛先レイヤーを固定し、衣装や背景が変わっても同じ女の子として認識させる。

📷 ② 光学物理シミュレーション

Sony α7R V ＋ 85mm f/1.4 G-Master (f/1.8)、1/320s、ISO 100 を指定。被写界深度の極上ボケ味と立体感を完全再現。

🔬 ③ 生体マイクロテクスチャ

鼻筋や頬の微細な毛穴、あごの微小な産毛、唇の縦ジワと潤い、瞳の環境光反射を記述し、CG感を完全根絶。

☀️ ④ 自然光 & 商業ライティング

夕暮れのゴールデンアワー、窓からの柔らかい朝の光、髪の毛のエッジを透過する自然なリムライト（Rim Light）を演出。

👗 ⑤ 布地・衣装の物理質感

ざっくり編まれたリブニットの太い編み目、リネンの自然なシワ、シルクの滑らかなドレープと陰影をリアルに再現。

🎞️ ⑥ フィルム階調科学 (Portra 400)

Kodak Portra 400 / Fujifilm Pro 400H の発色を模倣。デジタルの硬さを消し、雑誌スナップのような温かみある人肌を実現。

第2章：Web UI（ブラウザ・スマホ最適化）操作ガイド

🌐 アクセスURL: http://localhost:8086

スマートフォン（Chrome）から直感的に操作できます。画面上部にある「🎨 AI 画像＆実写スタジオ」カードの 「🎭 合成・編集スタジオ」 ボタンを押すと、専用モーダルが開きます。

🎭 1. 複数画像合成 (Fusion) 2枚以上の画像
  1. 上部タブで 「🎭 複数画像合成」 を選択。
  2. 点線枠をタップして、スマホのギャラリーから2枚以上の写真を選択（例: 人物写真 ＋ 夜景の写真）。
  3. プロンプト欄に合成指示を入力：
    2枚を自然に調和させ、人物が夜の銀座に立っている1枚の写真にしてください。
  4. 「✨ Gemini 3 で合成を実行」 をタップ。
🖼️ 2. プロンプト画像編集 (Edit) 1枚の画像
  1. 上部タブで 「🖼️ プロンプト画像編集」 を選択。
  2. 変形・着せ替えしたい元画像を1枚選択。
  3. プロンプト欄に変形指示を入力：
    顔立ちはそのままで、服を白の上品なニットセーターに変えて、髪型をポニーテールにしてください。
  4. 「✨ Gemini 3 で画像をプロンプト編集」 をタップ。
📸 3. 超リアル実写ポートレート (Photoreal) 画像不要・プロンプトのみ
  1. 上部タブで 「📸 超リアル実写ポートレート」 を選択（画像アップロード枠は自動で隠れます）。
  2. プロンプト欄に希望のシチュエーションを日本語で入力：
    表参道のテラスカフェで読書する21歳清楚系女子大生、優しい微笑み、午後の日差し
  3. 「📸 Gemini 3 で超リアル実写美女を生成」 をタップ。

第3章：Termux CLI ワンライナー操作ガイド

TUGUMIを起動していなくても、Termuxの通常のBashシェルから直接実行できる高速コマンドです。

📸 ① 超リアル実写ポートレート生成: tugumi-photo
# カフェデート・彼氏目線スナップを一発生成
tugumi-photo "代官山のおしゃれなカフェでアイスラテを飲んで微笑む22歳清楚系モデル、彼氏目線"
🖼️ ② 既存画像のプロンプト編集（着せ替え）: tugumi-image edit
# 顔立ちを維持したまま衣装と髪型を変更
tugumi-image edit /storage/emulated/0/TUGUMIDesk/Images/model.jpg "服を白ニットに変えて、髪型をポニーテールにして"
🎭 ③ 複数画像の1枚合成: tugumi-image compose
# 人物と背景の2枚を自然に融合
tugumi-image compose model.jpg night_scene.jpg "モデルを夜景の展望デッキに自然に立たせて"
📺 ④ ターミナル内カラーアスキーアート表示: tugumi-image ascii
tugumi-image ascii /storage/emulated/0/TUGUMIDesk/Images/model.jpg

第4章：TUGUMI-CLI（対話モード）操作ガイド

対話画面（~/TUGUMIv6/start_cli.sh）では、スラッシュコマンドまたは自然言語でつぐみにお願いできます。

コマンド / 入力例 動作
/photo <指示> 超リアル実写ポートレート一発生成（一眼レフ仕様自動適用）
/image edit <パス> <指示> プロンプトによる衣装・背景・ポーズ編集
/image compose <P1> <P2> <指示> 複数画像の一枚融合・シーン合成
/image 対話型メニュー表示（1:実写, 2:一般, 3:編集, 4:合成）
「表参道で微笑む清楚系モデルの写真作って」 自然言語から意図を自律検知して実写生成を実行

第5章：商用AI美女モデルビジネス収益化ガイド

💡 成功の最重要コア: 「同一人物性（Character DNA）」の徹底

投稿ごとに顔が変わるAIアカウントはファンがつきません。最初に「看板モデルのマスターフェイス」を1枚生成し、日々の投稿はすべてその画像を元に Edit（画像編集） または Compose（合成） で生成することが鉄則です。

「21歳都内女子大生の日常」としてカフェや散歩、自撮りスナップを毎日投稿。

マネタイズ: 楽天ROOM、Amazonアソシエイト（コスメ・私服アフィリエイト）。
② Amazon Kindle 写真集出版 (KDP)

60〜80枚の高精細カットをまとめ「AIグラビア写真集」としてシリーズ出版。

マネタイズ: Kindle Unlimited 既読ページ報酬（KENP：1ページ約0.5円の不労所得）。
③ Fanbox / Fantia 会員サブスク

SNSから誘導した熱狂的ファン向けの限定未公開カット・超高画質原寸配信。

マネタイズ: 月額500円〜2,000円のストック収入（100人で月5万〜20万円）。
④ B2B アパレル着用撮影代行

ネットショップ（BASE・メルカリ等）の商品写真をモデルに着せて合成・納品。

マネタイズ: 1着あたり2,000円〜3,000円の受託制作（モデル・撮影費の代替）。
