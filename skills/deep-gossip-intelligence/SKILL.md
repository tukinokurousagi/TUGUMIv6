# Deep Gossip Intelligence: 噂話・裏話・炎上深層解剖スキル

このスキルは、表層的なWikipedia情報や公式発表の綺麗事だけでは決して見えてこない、**「ネットで囁かれた噂話」「物議を醸した炎上騒動の真相」「ファンの間で語り継がれる裏話・エピソード」「人間関係の確執や孤立疑惑の背景」**を徹底的に深掘りし、愛あるファン目線と客観的証拠の両面から多角的に解剖するためのスキルです。

---

## 1. コア設計思想（なぜ裏話・噂話を掘るのか）

1. **表層情報の完全脱却**:
   生年月日や所属事務所、シングル発売日といった誰でも知っている情報は最小限の表で済ませる。主役はあくまで「水面下のリアルな人間模様・言説・事件」である。
2. **アンチ誹謗中傷と「愛あるファン・ウォッチャー視点」の峻別**:
   単に悪口や誹謗中傷を垂れ流すのではなく、「なぜファンがざわついたのか」「どんな文脈で発言が切り取られたのか」「本人のキャラクターと大衆心理の摩擦はどこにあったのか」を愛情と知性を持って深く読み解く。
3. **具体的エピソードの徹底追求**:
   抽象的な言い回し（「過去の発言を巡る批判」等）を絶対に避け、「靴隠し発言によるいじめ疑惑」「クリスマスパーティー不参加の孤立説」「『私より頭がいい人』発言による学歴マウント炎上」など、**具体的な番組名・シチュエーション・言動**を明記する。
4. **噂・デマと客観的事実の仕分け**:
   「ネットの信憑性は当てにならない」ことを前提としつつ、「火のない所に煙は立たない背景」「出所となった投稿や切り抜き」「実際の真相（バラエティのネタ、多忙によるすれ違い、後のエッセイでの告白等）」を多面的に検証する。

---

## 2. 索敵・リサーチプロトコル

本スキル発動時は、以下のクエリパターンを用いて「裏側のリアルな言説」を多角索敵する。

### 索敵クエリ構成
1. **噂・疑惑の起点**: `{対象} 噂 疑惑 理由 なぜ`
2. **炎上・物議の経緯**: `{対象} 炎上 批判 マウント 失言 騒動`
3. **人間関係・裏話**: `{対象} 不仲 いじめ 孤立 ハブられ 舞台裏 エピソード`
4. **本人の本音・肉声**: `{対象} 本音 告白 葛藤 インタビュー エッセイ`

---

## 3. レポート構成フレームワーク

出力するMarkdownレポートは以下の見出し構成を基本とする：

```markdown
# {対象} 裏話・噂話・炎上深層インテリジェンスレポート

## 1. エグゼクティブサマリー（表と裏の二面性）
- 表の顔（現在の公式肩書・主要実績）
- 裏の顔・ネット上のパブリックイメージと論争点

## 2. ネットを揺るがした3大噂・炎上・裏話の深層解剖
| 事件・噂のテーマ | 発端・出所 | 拡散状況・ファンの反応 | 実際の真相・その後の展開 |
| :--- | :--- | :--- | :--- |

### 🔍 注目エピソードの深層ディープ解説
- 具体的な発端となった番組・投稿・発言
- なぜアンチやファンの間で大騒動になったのか
- 本人の意図、その後の釈明やエッセイでの告白

## 3. 人間関係・グループ内の力学と孤立・不仲疑惑の検証
- 同期・先輩・共演者との実際の距離感
- 「孤立」「ハブられ」と囁かれた背景（単独活動の多さ、多忙、キャラクターの特異性）

## 4. 当事者の肉声・インタビューから見える「素顔と本音」
- 著書やロングインタビューで吐露された本音
- 「期待を鎧にして自分を麻痺させていた」等の生々しい葛藤

## 5. 総括：なぜ彼女／彼は語られ続けるのか（愛ある総括）
- 強い光が生み出す影の濃さ
- ファンを惹きつけてやまない多面的な人間的魅力の結論

## 6. 照合一次ソース一覧
```
