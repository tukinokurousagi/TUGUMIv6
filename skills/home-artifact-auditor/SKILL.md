# Home Artifact Auditor

## When to Use
- ホームディレクトリ配下に`.ping`や一時キャッシュ等の不要なファイルが蓄積しているとき。
- ファイルの生成元プロセス、タイムスタンプ、保持要否を安全に調査・整理したいとき。

## Prerequisites
- TermuxまたはLinux環境のシェルアクセス権限
- `find`, `stat`, `lsof` (または `fuser`), `python3`

## How to Run
`python3 audit_artifacts.py --pattern ".ping*" --target "$HOME"`

## Quick Reference
- ファイル一覧と最終更新日時確認: `ls -lat $HOME/.*ping* 2>/dev/null`
- 開いているプロセスの特定: `lsof +D $HOME | grep ping`
- 安全な削除シミュレーション: `find $HOME -maxdepth 1 -name ".ping*" -mtime +1`

## Procedure
1. **対象ファイルの走査とメタデータ収集**: 対象パターン（`.ping*`等）に合致するファイルのサイズ、更新日時、inode情報を収集する。
2. **使用中プロセスの検知**: `lsof`または`/proc`を参照し、現在書き込みや参照を行っているバックグラウンドプロセスが存在しないか検証する。
3. **内容と生成元の特定**: ファイル内容の先頭数行を確認し、ヘルスチェックやIPC通信用の一時フラグであるか判定する。
4. **要否判定と報告**: 過去ログや完了済みヘルスチェックの一時ファイルであれば安全に削除可能と判定し、ユーザーに提示する。
5. **クリーンアップの実行**: 必要に応じて古い世代のみを削除し、再発防止のローテーション策を提示する。

## Pitfalls
- 稼働中デーモンがロックファイルや死活監視ソケットとして利用している場合、即座に削除するとサービスが異常停止する可能性があるため、事前にプロセスバインドを確認すること。
- ワイルドカード削除（`rm -f .*`）を直接実行すると、`.bashrc`や`.config`等の重要な隠しファイルを巻き込む危険があるため、必ず完全一致パターンで絞り込むこと。

## Verification
- 対象ファイル群の消去後、関連バックグラウンドサービスが正常に稼働を継続しているかプロセスステータスを確認する。
