# 安倍晴明『占事略决』六壬神課 現代風戦略占断スキル (senji-ryakketsu-rokujin)

## 概要
平安時代の天才陰陽師・安倍晴明公が遺した現存唯一の秘伝書『占事略决（せんじりゃっけつ）』全36箇条の数理体系を完全にプログラム化。
太陽黄経による二十四節気中気・十二月将の確定、十干寄宮、天地盤の立体展開、四課の抽出、九宗門（賊克・比用・渉害・遥克・昴星・別責・八専・伏吟・返吟）による三伝算出、十二天将（昼夜貴人・順行逆行）の配当を厳密に行います。

安直なランダムおみくじや抽象的な精神論を排し、
- **【現在・発端】初伝**
- **【展開・試練】中伝**
- **【結末・果実】末伝**
の時系列タイムラインを現代のビジネス、投資、キャリア、人間関係に翻訳し、
**「今すぐやるべき事 (DO)」**、**「絶対に避けるべき事 (DON'T)」**、**「勝負の時機」**、**「守護神将からの神託」** を明確に提示します。

## 占事略决・基本数理体系（エンジンの核心ロジック）

- **月将（太陽黄経）**:
  - 雨水(330°)亥(登明) / 春分(0°)戌(河魁) / 穀雨(30°)酉(従魁) / 小満(60°)申(伝送)
  - 夏至(90°)未(小吉) / 大暑(120°)午(勝光) / 処暑(150°)巳(太乙) / 秋分(180°)辰(天罡)
  - 霜降(210°)卯(太衝) / 小雪(240°)寅(功曹) / 冬至(270°)丑(大吉) / 大寒(300°)子(神后)
- **十干寄宮（課十干法）**:
  - 甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑
- **十二天将**:
  - 貴人(大吉・社会的信用), 螣蛇(凶・怪異炎上), 朱雀(凶吉・情報発信文書), 六合(吉・提携契約), 勾陳(凶・遅延膠着), 青竜(大吉・財運拡大), 天空(凶吉・虚妄企画断捨離), 白虎(大凶・急変衝突メス), 太常(吉・平穏報酬ルーティン), 玄武(凶・潜行裏切漏洩), 太陰(吉・深謀準備女性援助), 天后(吉・包容力柔軟適応)
- **昼夜貴人・順逆**:
  - 卯〜申時（昼貴人・旦） / 酉〜寅時（夜貴人・暮）
  - 地盤 亥子丑寅卯辰（陽宮）は順行 / 巳午未申酉戌（陰宮）は逆行
