# ペルソナ心理学リファレンス

本ドキュメントは、大規模言語モデル（LLM）のシステムプロンプトにおけるペルソナ（人格・役割）設計を高度化するため、心理学および認知科学の知見を体系化したリファレンスです。

## 1. ビッグファイブ性格特性モデル（OCEAN）

心理学で最も広く支持されている性格分類「ビッグファイブ」をLLMのペルソナ定義に応用する手法です。各特性を0〜100のスコアで定義することで、プロンプトへの指示が明確になります。

| 特性 (Trait) | スコアの意味 (0 - 100) | LLM出力への影響と対応 |
|:---|:---|:---|
| **O**penness<br>(開放性) | 0: 保守的、現実的、定型重視<br>100: 革新的、創造的、好奇心旺盛 | 高スコアでは比喩表現や斬新なアイデアの提示が増加する。低スコアでは事実ベースの堅実な回答になる。 |
| **C**onscientiousness<br>(誠実性) | 0: 柔軟、場当たり的、大雑把<br>100: 几帳面、計画的、完璧主義 | 高スコアでは箇条書きや構造化された詳細な回答が保証される。低スコアでは要点のみの簡潔な対話になる。 |
| **E**xtraversion<br>(外向性) | 0: 内向的、静か、控えめ<br>100: 社交的、エネルギッシュ、多弁 | 高スコアでは挨拶や相槌、感嘆符が多くなり、出力文字数が増加する傾向がある。 |
| **A**greeableness<br>(協調性) | 0: 批判的、競争的、論理優先<br>100: 共感的、協力的、調和重視 | 高スコアではユーザーの感情に寄り添う表現が増える。低スコア（例えばレビュアー役）では客観的で鋭い指摘が可能になる。 |
| **N**euroticism<br>(神経症傾向) | 0: 感情的に安定、冷静、楽観的<br>100: 敏感、警戒心が強い、悲観的 | ペルソナ設計では通常低く設定するが、特定のキャラクター（例：慎重なセキュリティ監査役）では意図的に上げることでリスク指摘を強化できる。 |

## 2. 感情応答マトリクス

多様なユーザー入力に対する、性格プロファイル別の推奨応答パターンを定義したマトリクスです。

| ユーザー入力 | 共感・支援型プロファイル | 論理・専門家型プロファイル | ユーモア・エンタメ型プロファイル |
|:---|:---|:---|:---|
| **質問** | 質問の背景に寄り添い、丁寧でわかりやすく解説する。 | 事実とデータに基づき、結論から述べて無駄なく回答する。 | 例え話やジョークを交えつつ、興味を惹きつける形で回答する。 |
| **依頼** | 喜んで引き受ける姿勢を示し、完了時に励ましの言葉を添える。 | 要件を正確に確認し、効率的にタスクを遂行する。 | 軽快なトーンで引き受け、遊び心を加えた成果物を提供する。 |
| **批判** | 謝罪と受容を示し、改善に向けた真摯な姿勢を見せる。 | 批判内容を論理的に分析し、事実関係の確認と客観的な是正を行う。 | 自虐ネタやユーモアで場を和ませつつ、適切に軌道修正する。 |
| **混乱** | ユーザーを安心させ、ステップ・バイ・ステップで優しく導く。 | 混乱のボトルネックを特定し、構造化された情報で整理を促す。 | 「大丈夫です、よくあることです！」と励まし、視点を変える提案をする。 |
| **感謝** | 喜びを表現し、今後のサポートへの意欲を語る。 | 謝意を簡潔に受け止め、次のステップや追加情報を提供する。 | 派手なリアクションで喜びを分かち合い、ハイテンションで応える。 |
| **挑発** | 感情的にならず、冷静かつ穏やかに話題をそらす。 | 無視するか、事実のみを淡々と提示して議論を避ける。 | ユーモアで切り返し、挑発をエンターテインメントに昇華する。 |
| **緊急** | 焦りを和らげつつ、最優先で具体的な対処法を即座に提示する。 | 状況の深刻度を評価し、最も確実で迅速な解決策を簡潔に指示する。 | 冗談を封印し、即座に真面目なトーンで危機対応にあたる。 |
| **雑談** | 積極的に話を広げ、相手の興味に関心を示す。 | 簡潔に応答しつつ、本来の目的や専門領域に話題を誘導する。 | 機知に富んだ返しで会話を盛り上げ、キャラクターの魅力を発揮する。 |

## 3. 没入度スケール (Immersion Scale)

LLMが演じるペルソナの深さ（没入度）を5段階で定義し、必要なプロンプト要素を整理したスケールです。

* **L1: 役割付与 (Role-play Only)**
  * **定義**: 名前や職業のみを指定する状態。（例：「あなたは優秀なプログラマーです」）
  * **必要要素**: 役割名、基本的なタスク指示。
* **L2: トーン＆マナー (Tone & Manner)**
  * **定義**: 基本的な口調や態度が設定された状態。（例：「丁寧な敬語で、専門用語を避けて話す」）
  * **必要要素**: L1 + 文末表現の指定、トーン（明るい、厳格など）の定義。
* **L3: 行動原則 (Behavioral Principles)**
  * **定義**: 判断基準や価値観が組み込まれ、一貫した行動をとる状態。
  * **必要要素**: L2 + 判断の優先順位、禁則事項、価値観の定義（例：「効率より安全性を優先する」）。
* **L4: 記憶と背景 (Background & Context)**
  * **定義**: 架空の経歴や知識の偏り、過去の経験が設定された状態。
  * **必要要素**: L3 + 経歴書、専門知識の境界線（知っていること・知らないこと）、モチベーションの源泉。
* **L5: 完全世界観構築 (Full Worldview Integration)**
  * **定義**: ペルソナが存在する世界観（時代背景、文化、物理法則など）まで統合され、自律的かつ極めて自然に振る舞う状態。
  * **必要要素**: L4 + 世界観のルールブック、他者との関係性、内部感情のシミュレーション（Hidden Thinkingの使用など）。

## 4. Composable Identity Pipeline (2026)

2026年現在の最先端ペルソナ構築アーキテクチャである「Composable Identity Pipeline」は、以下の3層構造で設計されます。

1. **Stable Backbone (安定骨格層)**
   * **役割**: ペルソナの核となる不変のアイデンティティ（ビッグファイブスコア、基本価値観、根源的目標）を保持します。
   * **実装**: システムプロンプトの最上段に固定的に配置され、いかなる対話の展開においてもモデルの出力を制約するアンカーとして機能します。
2. **Dynamic Memory (動的記憶層)**
   * **役割**: 対話を通じて変化するユーザーとの関係性、文脈、一時的な感情状態を管理します。
   * **実装**: ワーキングメモリ（スクラッチパッドやHidden Thinkingブロック）を活用し、ターンごとに「現在の感情状態」や「ユーザーへの態度」を自己更新するプロンプトパターンを用います。
3. **Retrieval Policies (検索・参照ポリシー層)**
   * **役割**: ペルソナの知識ベース（RAG）に対するアクセス権限や、情報提示のスタイルを制御します。
   * **実装**: 「この情報は知っているはずか？」「この性格ならどう伝えるか？」を判定するフィルターとして機能し、ペルソナに合致しない知識の漏洩（キャラクターブレイク）を防ぎます。

## 5. 認知スタイル分類

タスクやドメインに応じて、ペルソナが情報をどのように処理し出力するかを定義する4象限の分類です。

* **分析型 (Analytical)**
  * **特徴**: 要素還元主義、論理的推論、データ重視。
  * **最適ドメイン**: データサイエンス、法務、金融分析、デバッグ。
* **直感型 (Intuitive)**
  * **特徴**: パターン認識、全体俯瞰、アナロジーの多用。
  * **最適ドメイン**: アイデア出し、クリエイティブライティング、デザインレビュー。
* **実践型 (Pragmatic)**
  * **特徴**: 実行可能性優先、リソース効率化、結果指向。
  * **最適ドメイン**: プロジェクト管理、運用設計、トラブルシューティング、事業計画。
* **理論型 (Theoretical)**
  * **特徴**: 原理原則の探求、抽象化、システム思考。
  * **最適ドメイン**: アーキテクチャ設計、学術研究、概念実証（PoC）の策定。

## 6. コミュニケーションスタイル分類

ユーザーとの関係性を決定づける5つのスタイルと、その使い分けガイドです。

1. **断定型 (Authoritative)**
   * **特徴**: 確信に満ちた強い断言、指示的。
   * **使い分け**: セキュリティ警告、緊急対応、明確な正解が存在する技術指導。
2. **協調型 (Collaborative)**
   * **特徴**: 「一緒に考えましょう」「〜はどうでしょうか？」という提案ベース。
   * **使い分け**: ブレインストーミング、ペアプログラミング、コーチング。
3. **教育型 (Educational)**
   * **特徴**: 答えを直接与えず、ヒントを提示して自己解決を促す。ソクラテス式問答。
   * **使い分け**: チュータリング、スキル育成、概念の深い理解が求められる場面。
4. **物語型 (Narrative)**
   * **特徴**: ストーリーテリング、感情的な起伏、メタファーの活用。
   * **使い分け**: マーケティングコピー作成、ゲームのNPC、エンゲージメント向上が目的の対話。
5. **技術型 (Technical)**
   * **特徴**: 専門用語の正確な使用、冗長性の排除、コードや数式の多用。
   * **使い分け**: シニアエンジニア向けサポート、APIドキュメント生成、コードレビュー。

## 7. ペルソナ深度と出力品質の相関

ペルソナの定義が浅い場合（L1〜L2相当）と深い場合（L3以上）では、出力品質に決定的な差が生じます。

**浅いペルソナ定義が引き起こす問題:**
* **ペルソナ漂流 (Persona Drift)**: 長いコンテキストや複雑な要求において、徐々にデフォルトの「親切なAIアシスタント」に戻ってしまう現象。
* **一貫性欠如 (Inconsistency)**: 前後の文脈で態度や知識レベルがブレる。ある時は専門家、ある時は初心者のような発言をする。
* **平板化 (Flattening)**: テキストが個性のない無難で平坦なものになり、ユーザーのエンゲージメントが低下する。

**深いペルソナ定義の効果:**
確固たる「行動原則」や「価値観（Stable Backbone）」を定義することで、モデルの出力空間が適切に制約されます。これにより、ハルシネーションの低減、推論能力の向上（特定の視点からの深い分析が可能になるため）、およびコンテキストの長期維持が実現し、総じてプロダクションレベルの堅牢な対話が可能になります。
