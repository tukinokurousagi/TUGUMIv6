## 🔬 セーブデータ内部構造・オフセット完全解説

### 1. `STAGE.BIN`（ステージ・進行データ / サイズ: 307,200 bytes）

| オフセット | サイズ | データ型 | 説明 |
| :--- | :--- | :--- | :--- |
| `0x0000` | 4 bytes | uint32 | **暗号チェックサム**（改ざん検知。ツールで再計算必須） |
| `0x0040` | - | Table | 各セクションへのオフセットヘッダテーブル |
| `0x0440` | 4 bytes | uint32 | **現在所持資金**（リトルエンディアン） |
| `0x0444` | 4 bytes | uint32 | **通算獲得資金**（引き継ぎ計算用） |
| `0x0458` | 4 bytes | uint32 | **現在所持TacP**（リトルエンディアン） |
| `0x045c` | 4 bytes | uint32 | **通算獲得TacP**（引き継ぎ計算用） |
| `0x0468` | 8 bytes | ASCII | **直前クリアシナリオID**（例: `078a\0`） |
| `0x0470` | 8 bytes | ASCII | **次回開始シナリオID**（例: `001\0` = 第1話直行） |
| `0x04f0 - 0x510` | 32 bytes | bitfield | **Magicカスタマイズ GRADE解放フラグ** |
| `0x051b` | 1 byte | uint8 | **クリア回数（周回数）**（例: `0x01` = 1周クリア/2周目） |
| `0x051c` | 1 byte | uint8 | **SRポイント**（例: `0x1f` = 31） |
| `0x051e` | 1 byte | uint8 | **15段階改造可能フラグ**（`0x01` で解放） |
| `0x0658 - 0x0ec8`| 2160 bytes | Struct[90]| **強化パーツインベントリ**（90種、ストライド24バイト） |
| `0x20bb - 0x21c7`| 271 bytes | Struct | **女主人公枠**（カホ/アマリ、アクアマリン、誕生日 05 09） |
| `0x21ca - 0x22d6`| 271 bytes | Struct | **男主人公枠**（イオリ、アイオライト、誕生日 11 16） |
| `0xbd70 - 0x27618`| 152KB | Struct[202]| **パイロットテーブル**（202人、ストライド `0x1f8` = 504バイト） |

### 2. 強化パーツ構造体（各24バイト / オフセット: `0x0658 + i * 0x18`）

| 相対オフセット | 型 | 説明・重要ルール |
| :--- | :--- | :--- |
| `+0x00` | uint8 | **所持総数**（例: `0x03` = 3個所持） |
| `+0x01` | uint8 | **装備中カウント**（**超重要：`0x00` でなければ機体に装備できない！**） |
| `+0x02 - +0x03` | uint16 | 予約領域（通常 `0x0000`） |
| `+0x04` | uint8 | **解放フラグ**（`0x01` でインベントリに白文字表示） |

> [!CAUTION]
> **「強化パーツが選べない・グレーアウトする」の根本原因**
> 1周目のクリア前データをそのままコピーすると、機体にパーツを装備していたため `+0x01` が非ゼロ（装備中）のままになります。第1話〜第3話など未加入の機体がある状態でこれを読み込むと、ゲームエンジンが「別機体が装備中で残り在庫0」と判定し、選択不能になります。
> **対策**: `+0x01` を必ず `0x00`（未装備・フリーストック）にリセットすること。

---

### 3. パイロット構造体（各504バイト / オフセット: `0xbd70 + i * 0x1f8`）

| 相対オフセット | 型 | 説明 |
| :--- | :--- | :--- |
| `+0x00` | uint16 | **パイロットID (PID)**（例: 0x4b=75, 0x92=146） |
| `+0x04` | uint16 | **経験値 (Exp)**（(Lv-1)*500） |
| `+0x06` | uint16 | **撃墜数 (Score)**（60機以上でエースボーナス解放！） |
| `+0x08` | uint16 | **所持PP** |
| `+0x10 - +0x30` | bytes | **修得スキルプログラムスロット** |

---

### 4. `SYSTEM.BIN`（システムデータ / サイズ: 1,228,800 bytes）
* `0x0000 - 0x0004`: 暗号チェックサム（タイトルID: `SuperRobotWarsX_SYSTEM`）
* `0x051b`: システム全体のクリア回数
* `0x051e`: 15段階改造可能フラグ
* `0x28000 - 0x73000`: **中断セーブ（クイックセーブ / CONTINUE領域）**
  * `0x28000` から後ろは `STAGE.BIN` と完全に同一の構造。

3. 第1話戦闘マップ（女主人公なら『出会い、そして始まり』）が開始したら、メニューから **「中断セーブ（クイックセーブ）」** またはスロットにセーブを行う。

Termux上で `srw_alchemist.py` を実行し、1周目のデータから資産・撃墜数を全量注入：

```bash
python3 ~/.agents/skills/vita-srw-save-alchemist/scripts/srw_alchemist.py \
  /path/to/1st_play_STAGE.BIN \
  /storage/emulated/0/PSvita/ux0/user/00/savedata/PCSG01128/PCSG01128-STG-001/STAGE.BIN \
  50000000 300000
```
